# ✨ Personal Portfolio Website

Welcome to my personal portfolio! This website is designed to showcase my skills, projects, learning journey, and creativity through a clean, modern, and interactive design.

## 🌷 About the Project

This portfolio is built to create a professional online presence and highlight my journey as a Computer Science Engineering student specializing in Artificial Intelligence and Machine Learning.

The website focuses on a minimal aesthetic, smooth animations, attractive layouts, and a user-friendly experience.

## 🚀 Features

- Modern and aesthetic UI design.
- Responsive layout for different screen sizes.
- Smooth scrolling animations.
- Interactive elements and hover effects.
- Dedicated sections for skills and projects.
- Clean typography and attractive color combinations.
- Easy navigation.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, and animations.
- **JavaScript** – Interactive elements and dynamic effects.
